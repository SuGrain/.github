## 关于 SuGrain

SuGrain 专注于物联网解决方案与智慧粮食管理系统，结合人工智能、传感器技术与全栈开发能力，推动农业现代化落地。  
访问 [SuGrain 组织主页](https://github.com/SuGrain) 查看全部仓库。

## 仓库分类概览

- **后端服务**：面向物联网与粮食管理场景的 Java 微服务
- **前端应用程序**：面向业务使用的小程序与网页应用
- **人工智能与机器学习**：深度学习与计算机视觉相关项目
- **传感器与检测**：激光雷达及传感器数据处理
- **配置与基础设施**：组织配置、自动化与部署支持
